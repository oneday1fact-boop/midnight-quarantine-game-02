# 午夜禁區：食人醫生 V8

原創心理犯罪懸疑文字選擇遊戲，手機優先，無需伺服器，可部署至 GitHub Pages。

## 遊玩
- 開啟 `index.html`；或部署至 GitHub Pages。
- 點「進入醫院」開始。
- 對話逐字顯示；點「繼續」可讀下一句，打字中點擊可立即顯示整句。
- 點選選項推進劇情。選擇會改變線索、警戒、醫生距離及後續結局。
- 點右上角「音效：關」開啟瀏覽器合成的恐怖音效。

## GitHub Pages 部署
1. 解壓 ZIP。
2. 將 `index.html`、`game.js` 及 `assets/` 上傳至 repository 根目錄。
3. GitHub repository → Settings → Pages。
4. 選擇 Deploy from a branch，分支選 `main`、資料夾選 `/ (root)`，儲存。
5. 等待 Pages 發佈後開啟網站。

## V8 內容
- 原創心理攻防劇情：失蹤案、記憶操控、被竄改病歷及多重真相。
- 場景圖片會隨劇情切換。

## 注意
此版本的圖片由概念圖裁切、重新取樣及高品質 JPEG 輸出；重新取樣可以改善顯示尺寸與壓縮品質，但無法憑空還原原圖不存在的細節。建議後續逐張替換成獨立原生高清場景圖。
